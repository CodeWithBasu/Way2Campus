# 🚌 Way2Campus

A modern, real-time college bus tracking and notification system designed to keep students informed and drivers connected.

## 📖 About The Project

Waiting for the college bus without knowing if it's delayed, stuck in traffic, or dealing with a puncture can ruin a student's morning schedule. **Way2Campus** solves this by providing a dedicated platform for college fleets (managing buses 1 through 55+). 

It bridges the communication gap between bus drivers and students with live tracking and instant status updates, allowing students to plan alternate routes if unforeseen emergencies occur.

## ✨ Key Features

*   **🎓 Role-Based Access:** Dedicated interfaces for both **Students** and **Bus Drivers**.
*   **📍 Live Bus Tracking:** Map-based interface for students to see the exact location of their designated bus.
*   **🚨 Instant Notifications:** Drivers can send one-tap updates for delays, heavy traffic, or mechanical issues (e.g., flat tire/puncture).
*   **📱 Mobile-First Design:** Built with a beautiful, aesthetic, and responsive UI so students can check updates on the go.
*   **🚌 Fleet Ready:** Designed to handle multiple buses operating simultaneously.

*   **Language:** TypeScript
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
